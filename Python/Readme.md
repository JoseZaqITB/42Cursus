# Python Stuff

## Important!
This project is using an virtual enviroment in order to work with it.

So, in order to activate it use:

```bash
source .venv/bin/activate
```
and for deactivating it use:
```bash
deactivate
```

- flake8
-  pep8-naming: for naming rules ( automatically added to flake8 rules)
